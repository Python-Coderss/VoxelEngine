# CHANGELOG

## The Build Loop Drops the Shell (Oct 22, 2026)

`tools/devtest.bat` replaces `devtest.sh` with the same contract — incremental
`javac` over stale sources, direct JUnit, `--full`, `--all`, simple or
fully-qualified test names — and gets faster doing it: `xcopy /L /D` decides
staleness by comparing a source against its stamp file, so no shell
comparison is needed. Measured here: **660 ms** build+start and **1.4 s**
total warm, **3.6 s** after editing `Main.java`, and **819 tests in ~70 s** for
`--all`. `tools/convert_music.bat` ports the mono 96 kbps MP3 batch (recursing
subfolders, skipping files already converted), and the example mod keeps only
its `build.bat`. The four one-shot `tools/migrate*.sh` HudUI scripts were
dropped rather than ported: they rewrite `Main.buildInventoryUi` /
`updateInventoryUi`, which no longer exist there.

The docs follow the tooling: `knowledge.md` now records the batch traps that
bit during the port (`set /p` truncating a classpath line at 1024 chars, Git's
GNU `find` shadowing the batch builtin, `%TIME%` read as octal, CRLF needed
for `goto`/labels).

## Captions That Follow the Voice, and MCSM's Choice Row (Oct 20, 2026)

### Captions now start when the audio does
A caption used to appear at *request* time, while the clip was still decoding,
and its reveal was an estimate scaled by speed. On pitched or queued lines the
text ran ahead of the voice. Now the reveal is held until the OpenAL source
actually starts, and the reveal window and cue times use the real resampling
factor (`ClipVoice.playbackFactor`, speed × emotion pitch). A 2.5 s watchdog
falls back to the estimate when no audio device is present, so captions still
work silently.

### Words land on the pauses, not on a stopwatch
`CaptionTiming` reads the PCM that is about to play: 20 ms RMS frames, hangover
for consonant tails, short-gap bridging, then the words are distributed over
the voiced stretches by syllable weight. `tools/align_voice_clips.py` does the
heavier version offline with a local faster-whisper model, recording a start
time per word for every clip into `voice/clip_word_times.json`
(`ClipWordTiming`); the game prefers those measured times, scales them with
playback, and uses the PCM reader when a clip has no alignment.

### Four choices, laid out the way MCSM does it
The single prompt panel with `[1]`-prefixed lines is gone. Decisions now render
as a row of four translucent cards (`HudUI.choiceCards`), each with a gold
accent, the option text and its key hint; hovering brightens the card, clicking
it picks, and the countdown is a thin line beneath the prompt that turns amber
then red. Tutorial and point-and-click forks both fill all four slots.

## Villagers Think With a Neural Net, Spatial Sense Without One (Oct 20, 2026)

### The learned half of the villager brain
Villagers now plan with a small feed-forward network (`VillagerPolicy`) whose
weights are trained offline by `tools/train_villager_policy.py` and shipped as
`/ai/villager_policy.json` — 8 inputs (build pending, social opening, job site,
chaos, friend near, player near, threat distance, daytime), one 12-unit tanh
hidden layer, 5 outputs (build, socialize, work, wander, idle). It reaches
99.9% imitation of the utility policy it was trained on and runs in plain Java
floats: no runtime ML dependency, no model download. The loader validates the
feature and action order recorded in the file, so a mismatched export is
rejected instead of scoring the wrong columns; a missing resource falls back to
`VillagerBrain.chooseAction`.

### What is deliberately *not* learned
Survival is hard rules: swimming, a visible threat or active panic, and night
short-circuit the network in `VillagerBrain.decide`. The comedy layer
(`ComedyMind`, `Chaos`) still overrides low-stakes plans, and jobs still redirect
idle/wander beats through `jobSiteReady()`. So the net picks between work,
build, chat and loitering — it never decides to stand in lava for a laugh.

### Spatial sense without a network
`SpatialMind` gives the non-neural spatial competence an LLM lacks: safe-stand
and cliff tests, cell openness, threat-escape scoring, line-of-sight cover,
flanking cells and crowd separation. Panic fleeing now asks it for a real
escape cell (no cliffs, no dead ends) before falling back to the old geometric
sprint point.

## Dynamic Villager Voices, Model-Agnostic Artifact Audits, and a 2-Second Test Loop (Oct 20, 2026)

### Villagers speak their actual lines now
A villager line no recording could cover used to play an unrelated vocalization
with no caption. It is now spoken by a real neural voice:

- **`CoquiVitsTts`** runs a **fixed-voice (non-zero-shot)** Coqui VITS model
  trained on VCTK — 108 voices, no cloning, no service, no Python —
  in-process on ONNX Runtime beside the Kokoro character voices. `MisakiEnG2P`
  supplies the phonemes (so numbers, contractions and stress marks survive) and
  the VITS blank/scales convention is reproduced exactly, with a 0.1 s gap
  between sentences at 22.05 kHz.
- **One villager, one voice.** Each villager is assigned a speaker from the
  model's *closed* inventory deterministically from its entity id (`p225`…
  `p292`, sorted), so the same villager always sounds like itself and only
  voices the model actually trained on are ever produced.
- **Recordings still win when they fit.** `ClipIndex.bestWordMatch` answers
  exact transcript first, then word overlap; a match plays and captions that
  clip exactly as before. Only when no clip shares a word does the dynamic
  voice speak — and then the caption is the authored line, rendered from the
  same text, so sound and subtitle cannot disagree.
- Renders happen on the existing clip worker into the normal `VoiceCache`
  (`[DYNAMIC:<voice>]` key) and play through the same queue; the model probes
  once on that worker, never on a game thread. `-Dvoxel.voice.villager.dynamic=false`
  restores the clip-only voice.
- **`tools/fetch_villager_voice.py`** verifies (and can download, hash-checked)
  the bundle: ONNX input signature, the `<BLNK>` phoneme vocab, the contiguous
  `pNNN` speaker list, the 22.05 kHz config and the shared G2P dictionaries. A
  mismatched export is reported before the game quietly falls back to clips.

### Artifacts are measured, not hoped away
`SpectralAudit` is a new frequency-domain gate for neural output: gap hiss
(mean 4–10 kHz energy of quiet frames against the peak frame), **tonal whine**
(strongest 1–8 kHz peak over its local median, reported in dB and Hz),
**spectral bursts** (frame-to-frame flux spikes), **clicks** in quiet regions,
DC offset and clipping. `CoquiVitsTts` conditions every render (DC removal,
margin-trimmed silence cuts, edge fades, peak normalize) and the headless test
refuses to accept a render that fails the audit — a regression names the
artifact and its frequency instead of just failing.

Measured on real renders of four villager lines: gap hiss 0.00000, tonal whine
5.4–8.3 dB (against an 18 dB limit), 0 clicks/s, 0 clipped samples. `SpectralAuditTest` proves a synthetic 6 kHz whine, gap clicks and a
DC offset all fail, so the gate is not vacuous.

### The edit→test loop is 2 seconds
`tools/devtest.sh <TestClass>` compiles only stale sources with plain `javac`
and runs JUnit directly (`--all`, `--full` supported). Warm no-change run:
**2.2 s**; after editing one file **2.5 s** — and that measurement edits
`Main.java`, the 9k-line worst case (C1-only javac JIT: 2.6 s → 1.3 s for it).
Full rebuild 75 s; the whole suite in **50 s** (729 tests, versus several
minutes through Maven). Staleness is
tracked with per-source stamp files rather than a guessed `.class` name,
because several sources here emit differently-named top-level classes. Maven
remains canonical (`./mvnw -o test`).

## Neural Character Voices, Verified Without a Sound Card (Oct 19, 2026)

The cast no longer depends on the robotic SAPI/OneCore voices. Authored lines
are now spoken by **Kokoro-82M**, an open 82M-parameter neural TTS model running
in-process on ONNX Runtime:

- **Java-only pipeline** — `KokoroTts` loads `kokoro-v1.0.onnx`, keeps the model
  session warm and renders 24 kHz mono WAVs on the existing speech worker. The
  text frontend is `MisakiEnG2P`, the pure-Java port of the misaki en-GB G2P
  (stress marks, British vowels, numbers, contractions). No Python, no service,
  no eSpeak at runtime.
- **Model download** — `tools/fetch_kokoro.py` fetches the graph, all 54 style
  vectors, the config and the misaki dictionaries from the official kokoro-onnx
  release / hexgrad repos into `dev/voice-models/kokoro`, verifies sizes and
  writes a SHA-256 manifest (`--check` re-verifies). Models are not committed.
- **Casting** — each `VoiceProfile` has a Kokoro style: builders `bm_george`,
  the player `af_heart`, narration `bf_emma`, bosses `am_fenrir`, while
  villagers keep their recorded clips. Rate follows the existing profile
  percentages. Rendered lines keep the content-addressed WAV cache, so the
  first play synthesizes once.
- **Fallback chain** — Kokoro → installed Windows voices (WinRT/SAPI) → recorded
  clips → captions. `-Dvoxel.voice.engine=sapi|winrt` opts out of the model and
  `-Dvoxel.voice.tts=off` disables synthesis entirely.
- **Audioless verification** — speech is synthesis, not playback: the new
  `KokoroPhonemesTest` and `KokoroTtsHeadlessTest` render and write WAVs with no
  OpenAL device, and the full suite plus a 25 s boot probe were run with
  `ALSOFT_DRIVERS=null` (713 tests, 0 failures, no exceptions). Whisper
  transcription of the Java-rendered files returns the authored lines
  near-verbatim (builder/narrator exact; boss/player differ by one homophone).

## Game Feel Pass (Oct 19, 2026)

Movement, combat and damage now give the feedback players expect from a
modern first-person game:

- **Camera** — `CameraFeel` replaces the per-frame random camera jitter with a
trauma-based shake (amplitude follows trauma²; smooth deterministic noise,
frame-rate independent). Shake rotates the render basis only, so it never
moves the crosshair. Added a speed-driven head bob (walk/sprint, cancelled in
third person and cutscenes) and a smoothed sprint FOV kick.
- **Jumping** — coyote time (0.10 s) and jump input buffering (0.12 s): presses
just after leaving a ledge or just before landing now register. Holding Space
still auto-bounces as before.
- **Landing** — `Player.consumeLandingImpact()` reports fall speed once per
landing; the camera dips and shakes proportionally to the drop.
- **Damage** — any health loss flashes a red full-screen vignette
(`ctx.hurtFlash` + `HudUI.updateHurtOverlay`) and jolts the camera; mob, fall
and fire damage all feed it. Block break/place add a featherweight camera tick.

## Every Character Speaks, and Beds & Banners Are Real Multiblocks (Oct 17, 2026)

### The previously silent cast is voiced
Ancient builders, the player ("You"), the narrator and bosses used to perform
entirely in captions. They now speak their authored lines through a local
operating-system voice (Windows SAPI through PowerShell, with per-role rate and
pitch), so no model is bundled and no network service is called:

- `VoiceProfile` gives each role its own register — builders are measured and
  dry, the narrator is slower and lower, bosses sit below the builders, and the
  player answers brighter.
- `WindowsSapiTts` renders SSML to a mono WAV on a worker thread; lines are
  cached by profile+text, so a repeated line is synthesized once. Signed
  percentages travel as `n6`/`p6` codes because PowerShell's `-File` parser
  treats a leading minus as a parameter name.
- `CharacterVoice` publishes the exact authored text to the live captions,
  plays the rendered audio through `VillagerAudioManager.playRendered`, and
  falls back to the recorded clip corpus, then to caption-only, when no local
  voice exists. `-Dvoxel.voice.tts=off` forces that fallback.
- Cutscene beats (`CinematicSystem.publishScript`) are always voiced and never
  rate-limited; ordinary conversation keeps a 7 s per-speaker gap, and a line
  spoken both by a direct interaction and its cutscene is not doubled.
- Villagers keep their recorded add-on clips; `VoiceProfile.VILLAGER` never
  reaches the synthesizer.

### Headless and audioless verified
The whole suite (624 tests) passes with `-Djava.awt.headless=true` and
`ALSOFT_DRIVERS=null`. New coverage: `AudiolessVoiceTest` drives the bridge
with an uninitialized `VillagerAudioManager` (captions and cached renders still
happen, playback is a safe no-op), `DecorationModelsHeadlessTest` resolves every
decoration model's texture references straight from JSON with no GL context,
and `WindowsSapiTtsTest` pins the opt-out (`-Dvoxel.voice.tts=off`).

### Beds and standing banners join doors as multiblocks
- A bed is a foot cell plus a head cell on one horizontal axis. One `bed`
  item stamps both halves with the facing taken from the player's look,
  breaking either half removes the other, and every half drops one bed.
- A standing banner is a lower plus an upper cell with two cloth planes
  (north/south and east/west). It needs solid ground and a free cell above;
  breaking either half removes the column and drops one banner.
- `DecorBlocks` owns the id layout and partner math, `BedPair` and
  `BannerColumn` perform the voxel transitions, and `BlockInteraction` adds the
  player/entity/room checks. Models for four bed facings and both banner
  planes are generated by `tools/gen_bed_banner_models.py`.

## Doors Are Real Multiblocks Now (Oct 17, 2026)

A door item used to stamp a single lower block, so a placed door was half a
building block with nothing above it, and mining one half left the other
floating. Doors are now handled as one two-block column:

- **Placing** a door writes both halves at once. The wall axis comes from the
  face you click (side of a wall) or, when placing on a floor, from the
  direction you are looking, so the panel sits in the doorway instead of
  slicing across it.
- **Using** a door swings both halves to the 90°-rotated model and flips an
  open bit in the extra data. Using it again closes it. A column with a
  missing or mismatched half refuses to open rather than spawning a ghost
  panel.
- **Breaking** either half clears the other and drops exactly one door item;
  the block-to-item table already maps all four parts of each wood to one
  entry. Creative instant-break also clears the column.

The pair math lives in `DecorBlocks` (ids, partner, rotated counterpart) and
`DoorColumn` (place/toggle/remove against a `World`), both covered by
`DoorColumnTest` and `DecorationBlocksTest` without a GL context.

## Villager TV: eight channels with real scripts, cues and voices (Oct 6, 2026)

### The TV is now an actual station
Villager TV used to be four hard-coded text loops. It is now a broadcast: **eight
channels**, each with a callsign, a strapline, a tint and a running order of
named programmes — Off-Air, **VSN** (Villager Shopping Network), **WX** (Weather
& Time), **VNN** (Villager News), **VMC** (Villager Music Channel), **NAT**
(Villager Geographic), **KITCH** (Hrmm Kitchen) and **SPORT** (Villager Sports
Network). Channels 0-3 keep their original numbers, so saved worlds and `/tv`
still mean what they meant.

### The scripts are a document, not code
The whole schedule lives in `src/main/resources/voice/tv_guide.json`: channels →
programmes → scripted lines, each with an offset, a caption, the voice it is
spoken in and the music cue that starts with it. Rewriting a channel needs no
Java change. `TvGuide` parses it and rejects a broken schedule loudly (a line
outside its slot, an unknown cue, non-contiguous channel ids, a cue with no
notes) rather than broadcasting nonsense; a small built-in schedule is the
last-resort fallback so a packaging mistake can never leave a screen blank.
VNN alone scripts three programmes — the Nightly, a Nether field report and the
Cultural Corner — across 48 + 40 + 32 seconds.

### Music cues are sung, not sampled
Each cue is pure data (tempo, notes, gain) and renders through the **same**
clip-voice arrangement pipeline the Villager News intro already uses, so a theme
or a price sting is sung in villager syllables with no new audio stack and no
new binary assets. Twenty-two cues ship: `vnn_theme`, `headline_sting`,
`vsn_jingle`, `price_sting`, `weather_jingle`, `clock_chime`, `storm_warning`,
`vmc_theme`, `nature_bed`, `kitchen_jingle`, `sports_anthem`, `full_time` and
the rest. A cue's notes are fingerprinted into the render cache key, so editing
the score always produces fresh audio instead of a stale clip.

### Every voice is a real take from the consented collection
The station broadcasts from exactly one collection: the Villager News 1.0
Add-On recordings the index marks `kind="addon"`. `VillagerAudioManager` builds
an addon-only view of the catalog (`ClipIndex.restrictedToKind(TV_CLIP_KIND)`)
and resolves pinned clips, `topic` situation matches and caption matches all
through it, so a TV line can never be spoken by any other corpus. The scripts go
further and are *written from* that collection: all 87 lines are the transcripts
of actual takes, and `tools/bind_tv_clips.py` pins each line to the recording of
its own caption, so what the screen shows is what you hear. `--check` fails when
a pin is missing, names a non-addon clip, or says something other than the
caption. `Main` polls the system once per logical tick and only speaks on the
channel a viewer is watching, so a wall of screens left on the default channel
no longer narrates the whole village; tuning in plays the current line once and
then runs forward, and switching channels opens with a short station ident.

The Weather station keeps a **live strip** under its script
(`Live: Morning 6:40 AM | Clear skies, sunny`) so it still reports the actual
world clock and sky, which the old text-only channel did.

### On the requested specific voice actor
Nothing is cloned. The project already holds a collection of Villager News
recordings it is permitted to use, and the TV now draws exclusively from it —
the addon-only restriction above is enforced in code *and* asserted by
`TvAddonVoiceTest`, so a stray corpus clip cannot leak onto the station. A
different licensed or self-recorded pack still drops in cleanly through
`-Dvoxel.voice.index=<file>`; per-channel voice packs would additionally need
the audio manager to hold more than one clip library, which is an easy
follow-up.

## Dumb-Human AI, Clip Voice, Live Captions (Oct 4, 2026)

### Comedic "dumb human" AI (villagers and mobs)
- New shared psyche layer `ComedyMind` with a per-entity personality (boldness,
  distractibility, drama, incompetence) derived from the entity id. Villagers
  and hostile mobs run on the same mind, so a hunter and a farmer make the
  same kinds of mistakes.
- **Short attention span**: villagers abandon tasks to investigate shiny
  things (`DISTRACTED`), forget what they were doing mid-task (`FORGOT`,
  "Wait. What was I doing?"), and stand admiring nothing (`ADMIRE`). Mobs
  break off chases because something else got interesting (`DISTRACT`).
- **Confident then cowardly**: villagers strut toward danger acting tough
  (`STRUT`, "I am not scared of you!") and scream the moment it crosses their
  boldness-based coward distance ("Okay I am a LITTLE scared of you!"). Bold
  hunters swagger in at walking speed taunting (`MOB_TAUNT`); timid ones cut
  and run at the first hit (`MOB_COWARD`) regardless of health.
- **Herd panic & contagion**: fleeing villagers follow whoever is ahead
  instead of choosing an escape direction (conga lines), fear adopted from
  neighbors amplifies with the chaos level, and hunters trail the nearest
  packmate mid-chase instead of flanking.
- **Job incompetence**: building is slapstick — proud "Nailed it." on
  success, "Ow! My thumb!" on failure, and forgetting the job entirely,
  scaled by the incompetence trait. Failures feed the chaos meter.
- **Petty social drama**: pointless arguments (`ARGUE`), waves at the wrong
  person (`WRONG_WAVE`), loitering after the player (`FOLLOW_PLAYER`), gossip
  lines, and tripping over nothing while wandering.
- **Escalating chaos** (`Chaos`, ticked from EntityManager): screams, crowds,
  arguments, and blunders raise a village-wide meter that decays slowly. High
  chaos makes comedy more frequent, panic stickier, and herds dumber.
- All lines flow through the speech pipeline with delivery emotions and show
  up in the live captions.

### Voice: synthesis removed, recorded clips only
- The ONNX synthesis stack is deleted (Coqui VITS, RVC v2, Kokoro, Misaki,
  Rmvpe, model bundle/assembler, eval tools) along with the onnxruntime

  documented.
- **Synthesis-era Java is gone, not just unused.** `VillagerVoice` (the model
  loading/synthesis wrapper), `TestWavCompare`, the vocoder comb-whine removal

- **Profile fields a recording cannot honor are gone.** The RVC retrieval

  `SpeechOptions`; old dialogue catalogs and presets that still carry

## Dialogue Director & Pack-Hunter Mob AI (Sep 5, 2026)

### Improved dialogue system (`com.voxel.audio.DialogueDirector`)
- **Temperament**: every villager now has a stable personality (chattiness,
  cheerfulness) derived from their entity id, so the same villager always
  sounds like the same person.
- **Mood**: fear and wariness spike when hurt or when threats are seen and
  decay over time. Mood colors delivery through the voice pipeline — scared
  lines get louder, faster, higher-pitched delivery with `scared` emotion —
  and biases line selection toward panicked or calm text.
- **Memory**: recently spoken lines are excluded for 6 picks, so villagers
  stop repeating themselves in back-to-back chats; repeated interaction adds

- **Merged pools**: the editable `DialogueCatalog` and the built-in

## Base Voice Overhaul — Numbers, Acronyms, Prosody (Aug 25, 2026)

### Base TTS frontend (`CoquiFrontend`)
- **Numbers are spoken, not dropped**: digit runs now expand to English words
  ("310" -> "three hundred and ten", "1,256" -> "one thousand...", "0" ->
  "zero", 4+ digit runs support thousands/millions/billions). Previously the
  digit symbols were silently removed from the token stream, so any line
  containing a number spoke only the words around it.
- **Contractions stay glued**: "what's"/"we're" keep the apostrophe inside the
  word and hit their CMU dictionary entry instead of falling back to
  letter-by-letter pronunciation.
- **All-caps acronyms are spelled** ("TV" -> "tee vee") using real CMU letter
  names (the weak article "a" is remapped to "ay" = /eɪ/).
- **Money and percent attach to numbers**: "$5"/"5$" -> "five dollars",
  "50%" -> "fifty percent"; decimals "3.5" -> "three point five".

### Base TTS synthesis (`CoquiVitsTts`)
- **Sentence joins use the validated 0.1 s gap** (2205 samples at 22.05 kHz)
  instead of Coqui's 450 ms pad — multi-sentence lines no longer plod.
- **Emotion-aware base synthesis**: the VITS noise-scale inputs now respond to
  the line's emotion (angry crisp, sad/scared breathier, happy brighter) so
  the *base* carries the delivery before RVC ever sees it.

### Other
- Voice cache version bumped to v8; old clips regenerate automatically.
- New frontend unit tests for numbers, contractions, acronyms, currency.

## Mob AI & Villager Voice Improvements (Aug 25, 2026)

### Mob AI
- **Enemies stop wall-hacking**: hostile mobs now only refresh their memory of
  the player's position with a clear line of sight (voxel raycaster). They still
  hunt the last seen spot for a few seconds, then lose interest instead of
  walking through walls to your exact position.
- **PathFinder relaxation fix**: A* now keeps the best-known cost per cell and
  re-opens cells only when a strictly cheaper route is found, so a worse
  predecessor can never overwrite the came-from chain (previously produced
  bloated routes on flat terrain and wasted expansions).
- **Villager panic flees around obstacles**: on spotting a threat, villagers
  immediately pathfind an escape point opposite the monster (jittered so two
  villagers don't queue), fall back to the zigzag sprint when no route exists,
  and re-path when pinned against a wall.
- **Villagers pathfind home at night** instead of grinding into walls, and
  **wanderers now detect being stuck** and pick a fresh target instead of
  bumping an obstacle for the full 14 s window.
- New tests: raycaster line of sight, optimal-cost pathfinding, flee-point
  geometry; existing AI/voice suites updated and green.

### RVC voice
- **Per-line noise seed**: each dialogue line now draws its own deterministic
  RVC posterior noise (seed hashed from the clip), so artifacts no longer
  repeat identically on every line while the persistent voice cache stays valid.
- **Energy-scaled excitation**: the RVC noise input is scaled per frame by local
  RMS energy — pauses and unvoiced consonants carry less random excitation,
  cutting the steady hiss RVC synthesized into the gaps between words.
- **Median-smoothed pitch contour**: single-frame autocorrelation outliers
  (which RVC rendered as chirps/crackles) are removed with a 3-tap median over
  voiced runs only; real rises and falls are untouched.
- **Click-free output padding**: if the RVC graph returns a few samples short,
  the tail is now fade-ramped instead of hard-zeroed (no truncation click).
